# Ева и Макс — игра для Android TV / Яндекс Станции

Игра сделана на HTML5 (`app/src/main/assets/index.html`) и обёрнута в Android-приложение с полноэкранным WebView.
Управление: стрелки пульта — ходить, OK — действие или смена героя, «Назад» — пауза (в паузе есть кнопка «Выйти»).

## Вариант 1. Собрать на GitHub (ничего не устанавливая)
1. Создайте новый репозиторий на github.com и загрузите в него содержимое этой папки (Add file → Upload files, перетащить всё, включая папку `.github`).
2. Откройте вкладку **Actions** — сборка «Build APK» запустится сама (или нажмите Run workflow).
3. Через 3–5 минут в карточке сборки появится артефакт **eva-max-apk** — скачайте zip, внутри `app-release.apk`.

## Вариант 2. Android Studio
1. File → Open → выбрать папку `EvaMax`, дождаться синхронизации Gradle.
2. Build → Build App Bundle(s) / APK(s) → Build APK(s).
3. Готовый файл: `app/build/outputs/apk/debug/app-debug.apk`.

Из командной строки: `./gradlew assembleRelease` (нужен Android SDK, путь в `local.properties` или `ANDROID_HOME`).

## Как менять игру
Вся игра — один файл `app/src/main/assets/index.html`. Карта уровня — массив строк `SRC` в начале скрипта:
`#` стена, `.` пол, `B` ящик, `h` норка (только Макс), `K` ключ, `*` звезда, `L` рычаг (только Ева), `f` забор, `G` калитка, `C` сундук, `c` кот, `E`/`M` старт Евы и Макса.
После правки — снова собрать APK.

## Заметки
- APK подписан отладочным ключом — подходит для установки на свои устройства, не для публикации в магазинах.
- Голосовые подсказки идут через системный синтезатор речи; если русского голоса на устройстве нет, игра просто молчит.
- Шрифты подгружаются из интернета; без сети используются системные.
